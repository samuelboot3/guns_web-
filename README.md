# Guía de Pistolas (proyecto académico)

Sitio web sencillo e informativo sobre pistolas: catálogo, historia y normas de seguridad.

## Tecnologías
- PHP 8+
- JavaScript (filtro, buscador y modal)
- Bootstrap 5 y Bootstrap Icons (por CDN)

## Estructura
```
index.php        Página de inicio
catalogo.php     Catálogo con búsqueda y filtro
seguridad.php    Normas de seguridad
contacto.php     Formulario con validación en PHP
includes/        header, footer y datos
assets/          CSS y JavaScript
```

## Cómo ejecutarlo

1. en primer lugar ejecuta xampp o laragon para permitir la ejecucion de apache.
2. abre la terminal en vs y pon este  link:  C:\xampp\php\php.exe -S localhost:8000
4. por ultimo abre la pagina web con este link: http://localhost:8000
